# TravelAgency — фронтенд (Vue 3)

Виконав: Крижановський Олександр Романович, група Бз-121-24-1-ПІ, 2026.

Веб-інтерфейс для [TravelAgency WebAPI](https://github.com/01eksandr0/Bz-121-24-1-PI-2-backend). Окремий проєкт: спілкується з бекендом тільки через HTTP (JSON + JWT).

Стек: Vue 3 (Composition API, `<script setup>`), Vue Router, Pinia, Axios, Bootstrap 5, Vite.

## Запуск

Потрібен Node.js 18+ і запущений бекенд (http://localhost:5080).

    npm install
    cp .env.example .env      # за потреби змінити VITE_API_URL
    npm run dev               # http://localhost:5173

Збірка для розгортання: `npm run build` (результат у `dist/`).

## Можливості за ролями

| Роль | Що доступно |
|---|---|
| Гість | головна з гарячими турами, пошук турів (фільтри, сортування), готелі, рейси |
| Клієнт | + бронювання туру, номера, квитків; «Мої бронювання» зі скасуванням |
| Менеджер | + створення/редагування/видалення турів, усі бронювання, довідники (країни, регіони, готелі, номери, рейси) |
| Адміністратор | + керування ролями користувачів |

## Структура

    src/api/            HTTP-клієнт (axios) і функції для кожного маршруту API
    src/stores/auth.js  стан входу (Pinia): токен, користувач, ролі
    src/router/         маршрути і захист сторінок за ролями
    src/composables/    useAsync - стан завантаження і помилки
    src/components/     повторно використовувані компоненти (картка туру, вкладки бронювань...)
    src/views/          сторінки; manager/ і admin/ - для персоналу
    src/utils/format.js підписи переліків, формат цін і дат
